List of Interesting Things

2 MIN READ 333 WORDS
Home/Posts

A curated collection of interesting tools, services, guides, and resources that I’ve found useful or noteworthy.

Last updated: 07.09.2026

Archiving

  • RedditToMarkDown - Save Reddit threads as Markdown files.
    • Useful before mods remove posts or Reddit changes access rules.
  • Pandoc - Convert between different markup languages (e.g. HTML <-> Markdown).
  • Ente - Open-source, end-to-end encrypted alternative to Google Photos; also includes an authenticator app.
    • Use my referral code to get 10GB extra storage: DKSCPX

Development

  • SVG Tutorial - Learn how to code vector graphics in HTML with SVG.

Privacy

  • JustDeleteMe - Directory of direct links and instructions for deleting accounts from web services.
  • LocalSend - Open-source, cross-platform local network file sharing (AirDrop alternative) that works completely offline without accounts or external servers.

Utilities

  • IT-Tools - Handy collection of web-based developer and sysadmin utilities (GitHub).
  • Stirling-PDF - Powerful, locally hosted web application for PDF manipulation (merge, split, convert, OCR).

Torrenting

  • awesome-german-piracy - A curated list of (not only) German indexing and sharing sites.
  • German Torrents - Overview of German torrent trackers and indexing sites.

Screensharing

  • Pin.gl - Ultra-low-latency screen and camera sharing (browser-based).

Misc

  • Excalidraw - Virtual whiteboard for sketching hand-drawn diagrams.
    • Supports real-time collaboration with others.
    • Great for quick system sketches and architecture notes.
  • FossFlow - A tool to design isometric infrastructure diagrams (GitHub).
  • 4get - A privacy-focused proxy search engine that doesn’t track or filter results.
  • SmallDocs - A web-based Markdown editor with clean export and styling options.
  • Spotube - Open-source Spotify client that doesn’t require Premium or use Electron. Available for desktop & mobile.
    • I’ve donated to this project, by the way! ❤️
  • Website themes with uBlock Origin - Guide to injecting custom CSS themes into websites using uBlock Origin.
  • Displaying Website Content on an E-Ink Display - Write-up on rendering web content on low-power E-Ink screens.

Fonts

  • Commit Mono - A neutral, highly legible monospaced font engineered for programmers.
  • Departure Mono - A monospaced pixel font with a lo-fi, techy vibe.
  • Geist - A typeface specifically designed for developers and designers.
